# 图片处理工具箱

一个单文件浏览器图片处理工具，支持批量切图、批量缩放、批量裁切、转 PNG、长图拼接和多宫格拼图。

## 使用方式

直接用浏览器打开 `图片处理工具箱.html` 即可使用。所有图片处理都在浏览器本地完成。

## 功能

- 批量切图：二宫格、四宫格、九宫格
- 批量缩放：统一尺寸，支持锁定比例
- 批量裁切：交互式选框，全局应用
- 转 PNG：批量转换常见图片格式
- 拼接拼图：竖向/横向长图拼接，以及二宫格、四宫格、六宫格、九宫格等多宫格拼图
