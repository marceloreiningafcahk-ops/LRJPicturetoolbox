# 图片处理工具箱

一个单文件浏览器图片处理工具，支持批量切图、批量缩放、批量裁切、转 PNG、图片拼接和网格拼图。

## 使用方式

直接用浏览器打开 `图片处理工具箱.html` 即可使用。所有图片处理都在浏览器本地完成。

## 功能

- 批量切图：二宫格、四宫格、九宫格
- 批量缩放：统一尺寸，支持锁定比例
- 批量裁切：交互式选框，全局应用
- 转 PNG：批量转换常见图片格式
- 图片拼接：竖向或横向长图拼接
- 拼图：多图网格排版，支持列数、间距、圆角、背景色和导出格式
